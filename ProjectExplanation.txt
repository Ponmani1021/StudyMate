# StudyMate – Study Planner Web Application

## 1. What is StudyMate?

StudyMate is a personal study management web application that helps students organize their studies, manage assignments, plan their daily timetable, track their study time, and understand their academic progress in one place.

Normally, students use notebooks to write timetables, separate lists to remember assignments, mobile timers to track study hours, and other apps to monitor their progress. Managing everything separately can be confusing.

StudyMate brings these activities together into a single web application. Students can plan what to study, decide when to study, track what they complete, and review their progress.

The main goal is to help students study in a more organized, consistent, and productive way.





## 2. What problem does StudyMate solve?  ##

Imagine a college student who has five subjects, three assignments, an upcoming examination, and a goal of studying three hours every day.

The student might face these problems:

- Forgetting assignment deadlines.
- Not knowing which subject to study first.
- Having no proper daily study timetable.
- Spending too much time on one subject and neglecting others.
- Not knowing how many hours they actually studied.
- Being unable to measure whether their study habits are improving.

StudyMate is designed to address these problems through a set of connected features.




## 3. What can StudyMate do?

StudyMate will have seven main modules. Each module has a specific purpose.


## 1. Dashboard

Main page

The Dashboard gives students an overview of their study activities immediately after opening the application.

What it can do:

- Display the number of subjects and pending tasks.
- Show today's study schedule.
- Display completed and upcoming assignments.
- Show daily study goals and study-hour summaries.
- Provide quick access to other modules.

Example: A student opens StudyMate and sees two pending assignments, three study sessions planned for today, and 90 minutes of study completed.

This module helps students focus on studying for a selected period.

## 6. Progress & Analytics

This module helps students understand their study habits using the data recorded in the application.

What it can do:

- Display total recorded study hours.
- Show study time by day or week.
- Calculate task completion percentages.
- Compare recorded study time with daily goals.
- Display charts and progress summaries.

Example: A student discovers that they studied 12 hours this week and completed 80% of their tasks.

These are calculated summaries of recorded activity, not predictions of examination marks or guaranteed academic performance.

## 7. Settings

This module allows students to customize their StudyMate experience.

What it can do:

- Set a daily study-hour goal.
- Change between light and dark themes.
- Configure basic profile preferences.
- Export saved study data as a JSON file.

Example: A student sets a daily goal of three hours and enables dark mode for studying at night.

There will also be a Not Found page for invalid URLs. It is an error-handling page, not an additional study management module.

## 4. How will a student use StudyMate in real life?

Consider a student named Arun preparing for college examinations.

Step 1 — Organize subjects

Arun adds Python, DBMS and Computer Networks to his Subjects module.

Step 2 — Create a timetable

He plans to study Python in the evening and DBMS later that night.

Step 3 — Manage assignments

He records an assignment due tomorrow and gives it high priority.

Step 4 — Focus and record study time

He uses the Pomodoro timer while studying and records completed sessions.

Step 5 — Review progress

At the end of the week, he checks how many hours he studied and how many tasks he completed.

This is the core workflow: Plan → Organize → Study → Track → Improve.

## 5. What technologies will be used, and why?

StudyMate will initially be a frontend web application built using React JS.

| Technology     | Why we use it                                                                 |
| -------------- | ----------------------------------------------------------------------------- |
| HTML           | Provides the basic structure of the application.                              |
| CSS            | Controls colors, layouts, spacing and responsiveness.                         |
| JavaScript     | Handles calculations, interactions, timers and application logic.             |
| React JS       | Builds reusable components and updates the interface when data changes.       |
| Vite           | Creates and runs the React development project.                               |
| React Router   | Allows navigation between Dashboard, Subjects, Tasks and other pages.         |
| `localStorage` | Saves data in the browser so it remains available after a normal page reload. |
| Recharts       | Creates visual charts for study statistics.                                   |
| Lucide React   | Provides consistent icons for navigation and actions.                         |

### How will the data be stored?

For the beginner version, we will use browser `localStorage`. This means a student's subjects, tasks, preferences and study records can be saved on their device.

However, this version will not automatically provide cloud synchronization, multi-device access or secure user accounts. Those features would require a backend and database if we decide to add them later.

## 6. What StudyMate will and will not do

It is important to define the project scope before writing code.

Included in the planned project

Subject management, task management, timetable planning, Pomodoro timer, study-session records, progress charts, study goals, theme customization and data export.

Not included in the initial version

AI-generated study plans, automatic examination prediction, online classes, teacher/student collaboration, cloud synchronization, real authentication and automatic assignment reminders outside the application.

These advanced features could be considered in a future version, but we should not claim them as existing functionality unless we actually implement them.

## 7. What is the final outcome of this project?

When completed, StudyMate will be a responsive, interactive study planner website that allows students to manage their academic activities from one interface.

The finished application should enable a student to:

- Keep subjects and study tasks organized.
- Plan study sessions in advance.
- Remember deadlines and priorities.
- Track focused study time.
- Understand their progress through charts and statistics.
- Customize their study environment.
- Keep their information saved between visits on the same browser.

In simple words: StudyMate acts like a digital study assistant. It does not study for students; it helps them decide what to study, when to study, what work remains, and how consistently they are studying.

That is the theoretical foundation of the project. Before beginning development, we should use this scope to decide the exact screens, data fields, and behavior of each feature so that every part of the application works together consistently.
